# 01: Verify and launch the Windows workshop

**What to build:** A workshop participant can run one command that discovers installed tools, protects unrelated processes, runs every quality gate, starts or restores the shop, and verifies the complete public runtime path.

**Status:** ready-for-agent

- [ ] Stale-PATH tools are found and exact paths are reported.

- [ ] Missing workshop services are launched and all public runtime checks pass.
